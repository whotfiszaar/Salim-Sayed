# Salim-Sayed

Executive Portfolio for **Salim Sayed**, Retail Operations Leader based in Dubai, United Arab Emirates.

## Overview
- **15+ Years** of Retail Operations Leadership across the GCC and India
- **45+ Stores Launched** across 5 countries (UAE, KSA, Kuwait, Qatar, India)
- **AED 130M** commercial portfolio managed across 200+ retail professionals
- Built with **Next.js 16**, **Tailwind CSS 4**, and **TypeScript**
- **Urban Chic** luxury editorial design system (#22223B dark contrast)
- Interactive **Pinterest-style leadership gallery** with curated high-resolution photography

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4, CSS Masonry
- **Icons**: Lucide React
- **Animations**: IntersectionObserver Scroll Reveal, CSS Marquee
- **Typography**: Instrument Sans & Figtree

## Getting Started
```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
